# Third-party source reference

The optional NumPy LCM scheduler follows the equations and behavior of Hugging Face
Diffusers v0.32.1 `LCMScheduler`, by the Diffusers contributors, under Apache-2.0.
The unmodified upstream license is retained in `Diffusers-Apache-2.0.txt`.

Source: https://github.com/huggingface/diffusers/blob/v0.32.1/src/diffusers/schedulers/scheduling_lcm.py

Model weights and their separate licenses are downloaded only by explicit project
setup tools; they are not part of this source repository. See the root NOTICE.
