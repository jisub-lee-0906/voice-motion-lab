# BOP! MV v0.3 — 로컬 뮤직비디오 제작기

이 버전은 대회 출품을 목표로 한 **음악 → 가사 분석 → 2D 연출 → 실제 MP4**
제작 경로입니다. 공개된 5초 BOP! 브라우저 앱과 별개로, 이 PC에 설치한 전용
CPU 백엔드와 독립 ComfyUI를 사용합니다. 모바일 무서버 제작 조건은 이 고급
경로에서 해제했습니다. 공개 기본 앱은 그대로 유지합니다.

실제 UI에서 32초 합성 데모를 실제 ASR·단어 정렬·공식 SDK 경로로 제작해
13컷 MP4를 완성했습니다. 해당 실행은 약 46초였고 일반 곡이나 다른 PC의 속도를
보장하지 않습니다. SDK 결과 메타데이터 처리에서 발견한 오류는 수정했습니다.
WebM 미리보기를 포함한 최종 재검증은 약 49초였으며 실제 재생·MP4 다운로드·
새로고침과 앱 재시작 후 결과 복구를 확인했습니다. MP4 파일 경로의 숫자 확장자를
거절하던 오류를 수정했고 네 종류의 파일과 범위 응답을 회귀 검사합니다.
제작 완료와 브라우저 재생, 자연 가창 품질, 출품 자격은 서로 다른 검증 항목입니다.
최신 검증 결과는 루트 `VERIFICATION.md`의 버전별 기록을 확인하세요.

## 무엇을 만드나요

1. 최대 60초의 음악 파일 하나를 고릅니다. 첫 시도는 **15–45초**를 권장합니다.
2. 테마를 음악에 맡기거나 피어나는 세계·깨지는 세계·맴도는 세계 중 고릅니다.
   가사 입력은 선택 사항이며, 기본 경로는 실제 자동 전사입니다.
3. **뮤직비디오 만들기**를 누르면 가사를 인식하고 단어 시점을 맞춘 다음,
   음악의 변화와 가사 단서를 이용해 장면을 구성합니다.
4. 완성 결과는 **960×540 / 24fps / H.264·AAC MP4**, 장면별
   `storyboard.jpg`, 편집 가능한 연출 `project.json`입니다. 제공되는 경우 화면은
   호환성을 위한 `preview.webm`으로 재생하고, 영상 저장은 원래 MP4를 받습니다.

입력 파일 선택·미리듣기만으로 서버에 전송하지 않습니다. 만들기를 누를 때
브라우저가 파일을 디코딩하고 채널을 합친 뒤 16kHz 모노 PCM을 전송합니다.
60초를 넘으면 업로드 전에 거절합니다. 현재 결과 영상의 소리는 이 변환본에서
제작되며, 원본 파일의 스테레오 음질이나 비트 단위 보존을 약속하지 않습니다.

## 실제 실행 구조

```text
브라우저 :8797
  └─ 음악 디코딩 / 16kHz 모노 / 명시적 Create
      └─ mv_server.py, 한 번에 작업 하나
          ├─ 프로젝트 .comfy-venv의 CPU 모델 subprocess
          │   ├─ Qwen3-ASR-0.6B-hf: 실제 가사 전사
          │   └─ Qwen3-ForcedAligner-0.6B-hf: 실제 단어 시점 정렬
          └─ 공식 comfy-sdk 0.5.0
              └─ 프로젝트 API v2 proxy 0.1.6 :8795
                  └─ 독립 ComfyUI :8794 / VoiceMotionMVCreate
                      ├─ 음악 분석 + 가사 기반 연출 계획
                      ├─ Pillow·PyAV CPU 장면 렌더링과 원음 결합
                      └─ MP4 / JSON / 스토리보드 실제 파일 반환
```

SDK는 장식용 호출이 아닙니다. SDK로 실행하는 그래프의 노드가 음악 분석,
장면 계획, 최종 렌더링을 수행하고 API v2에서 실제 결과 파일을 회수합니다.
직접 엔진 호출로 몰래 전환하거나 클라우드 엔드포인트를 기본값으로 사용하지
않습니다. 이 설계의 실제 종단 검증과 대회 요구사항 충족 판단은 구분합니다.

화면은 `queued → transcribing → directing → rendering → succeeded/failed`
상태와 서버가 알려 준 진행률을 표시합니다. 완료되지 않은 영상을 완료로
표시하거나 대기 시간을 가짜 진행률로 꾸미지 않습니다. 안전하게 특정 SDK
작업을 취소하는 기능은 아직 없으므로 취소 버튼도 없습니다. 페이지를 떠나도
로컬 작업은 계속될 수 있으며 같은 탭에서 새로고침하면 작업 상태를 재조회합니다.

## 모델·설치·시작

Windows와 프로젝트 전용 Python 환경을 사용합니다. **다른 ComfyUI 설치의
Python으로 아래 명령을 실행하지 마세요.**

```powershell
./tools/setup_mv.ps1 -Python python
./start-mv.ps1 -StartEngines
```

그다음 **http://127.0.0.1:8797/**을 엽니다. `-StartEngines`는 프로젝트의
독립 Comfy와 프록시를 준비합니다. 해당 포트가 다른 소유자의 서비스로 점유되어
있으면 임의로 연결하거나 종료하지 않고 실패합니다. 외부에서 모바일로 접속할
수 있는 공개 서버 설정은 포함하지 않습니다.

앱을 직접 실행한 터미널에서는 작업이 끝난 후 `Ctrl+C`로 종료합니다.
추적된 백그라운드 프로세스를 종료할 때는 `./stop-mv.ps1 -WhatIf`로 대상을
먼저 확인한 뒤 `./stop-mv.ps1`을 사용합니다. `-IncludeComfy`를 추가해야
이 프로젝트의 독립 Comfy까지 대상이 됩니다. 기본 8793 앱은 대상이 아닙니다.
PID·스크립트·소유자·진행 작업을 검증할 수 없으면 종료를 거부합니다.

환경은 `.mv-venv`(웹 서버·SDK·프록시)와 `.comfy-venv`(독립 Comfy·CPU 모델)
두 개입니다. 가사 모델은 `.runtime/mv-models/asr`와 `aligner`에 저장합니다.
두 가중치 파일의 합은 약 **3.4GB**이며 Python 런타임·의존성·캐시는 별도입니다.
설치 시 고정 revision과 공식 Git/LFS 해시를 검증합니다.

| 모델 | 고정 revision | 라이선스 |
|---|---|---|
| `Qwen/Qwen3-ASR-0.6B-hf` | `7f1569a48a89f3e3f4dc3a5c9d28bddd903bc76c` | Apache-2.0 |
| `Qwen/Qwen3-ForcedAligner-0.6B-hf` | `c07281df297b9905d24a508279258cccf987a064` | Apache-2.0 |

실행 시 모델 다운로드를 하지 않으며 로컬 파일만 읽습니다. ASR과 정렬 모델을
순서대로 사용하고 CPU 스레드는 2개로 제한합니다. GPU를 사용하지 않습니다.
Windows에서 가용 RAM이 5GB 미만이면 새 작업을 거절합니다. 이 제한만으로 다른
작업과 모든 자원 충돌이 없어지는 것은 아니므로, 무거운 실행 전에 공유 자원을
확인해야 합니다. CPU 처리 시간은 곡 길이와 장치에 따라 달라집니다.

수동 가사를 입력하면 전사 출처가 `provided_lyrics`로 기록되고 공개 정렬 모델로
발음 시점을 맞춥니다. 자동 인식 결과와 사용자가 준 문장을 혼동하지 않습니다.
반주가 강한 노래·왜곡된 발음·합창·다국어에서는 전사와 정렬이 틀릴 수 있으며,
정답 가사를 몰래 넣지 않습니다. 현재 테마 추론은 한국어·영어 어휘 규칙이며
범용 언어 모델의 깊은 가사 해석으로 설명하지 않습니다.

## 현재 미술과 연출의 범위

현재 기본 MV는 프로젝트가 직접 작성한 **절차적 2D 일러스트·캐릭터 동작**을
사용합니다. 반복 캐릭터, 색 체계, 상징의 변화, 여러 구도와 포즈, 음악의 실제
에너지·스펙트럼 변화에 맞춘 전환을 갖춘 연출 초안입니다. 가사 단서와 반복
구절을 규칙으로 연결합니다. 이 영상을 이미지 생성 AI가 만든 작품이나 참조한
작가와 동등한 완성도로 표현하지 않습니다.

원하는 수준으로 발전시키려면 생성 일러스트 팩, 포즈·캐릭터 일관성, 더 풍부한
장면 전개와 가사 의미 해석을 추가해야 합니다. 코드의 레이어/렌더러 경계를
확장 지점으로 둡니다. 선택형 **CPU OpenVINO LCM 일러스트 실험**도 별도로
검증했으나 두 번의 실제 CPU 결과가 평면 미술 지시를 충분히 따르지 않아 채택하지
않았습니다. 현재 기본 파이프라인이 아닙니다. `setup_mv_illustration.py`를 일반 MV
설치의 필수 단계로 실행하지 않으며, 미검증 결과를 기본 기능으로 약속하지 않습니다.

## 데모와 개인정보

화면의 데모 버튼은 **이 프로젝트에서 만든 32초 절차적 음악 + Microsoft Zira
합성 TTS 발화**를 명시적으로 불러옵니다. 자연스러운 가창이나 실제 사람의 녹음이
아닙니다. 데모의 예상 가사 파일은 시험용 출처 자료이며 정상 제작 요청에 정답으로
주입하지 않습니다. 가사 입력란을 비워 두면 데모도 실제 ASR·정렬을 거칩니다.
자연 가창에 대한 품질 검증은 별도로 남아 있습니다.

| 위치 | 보관 내용 |
|---|---|
| `input/mv/<job-id>/` | 변환된 `source.wav`, 선택 입력한 가사 |
| `output/mv/<job-id>/` | MP4·연출 JSON·스토리보드·전사·작업 메타데이터·해당 작업 로그 |
| `.runtime/mv-proxy-state/` | 프로젝트 프록시의 상태 파일 |
| `.runtime/mv-models/`, `.cache/`, `temp/` | 이 프로젝트 모델·캐시·임시 자료 |

입력과 결과는 프로젝트 폴더에 남습니다. 위 런타임·입출력 경로는 Git에서
제외되며 사용자 음악·가사를 GitHub나 외부 추론 서비스로 전송하지 않습니다.
연출 JSON에는 전사 텍스트가 포함되고 MP4에는 소리가 포함되므로 직접 공유하기
전에 내용을 확인하세요. 자동 만료·자동 정리는 구현하지 않았습니다.

## 공개 앱·대회 제출과의 관계

[공개 BOP! v0.2](https://jisub-lee-0906.github.io/voice-motion-lab/)는 서버 없이
브라우저에서 5초 소리를 모션과 밈 영상으로 만드는 별도 도구입니다. 이 로컬 MV
백엔드는 GitHub Pages에서 실행되지 않으며 공개 링크에 추가 배포하지 않았습니다.

공식 SDK의 실제 실행과 결과 파일 회수를 검증했습니다. **2분 시연 영상, 자연
가창 결과의 품질 검증, 필요한 SNS 게시와 대회 최종 제출은 아직 진행하지 않았습니다.**
대회 규정은 별도 확인 대상이며 SDK 호출 하나만으로 출품 자격을 보증하지 않습니다.
기존 사용자의 ComfyUI Studio·워크플로우·모델·환경·서버는 변경하거나 이용하지 않습니다.
