## 우리 작업에 적용할 해석

이는 관찰에서 얻은 제작 판단이며 원작의 제작 기법을 알아냈다는 주장이 아니다.

- 좋은 그림 한 장의 디테일보다 **구도·포즈·전경·명암 덩어리**를 먼저 잡는다.
- 와이드·미디엄·손·얼굴로 화면 크기를 크게 바꾸되 같은 의상과 소품을 이어 준다.
- 손과 몸은 이야기의 동사다. 인물 전체를 흔들고 확대하는 것만으로 행동을 대신하지 않는다.
- 전경이 인물을 일부 가리고 뒤 공간이 분리되어야 한다. 단순 배경 위 인물 스티커 합성으로 끝내지 않는다.
- 색은 장면마다 무작위로 바꾸지 않는다. 같은 팔레트 안에서 어둠과 밝은 공간의 비중을 바꾼다.
- 질감·노이즈·타이포는 구도와 행동이 성립한 뒤 추가한다. 장식으로 미완성 동작을 숨기지 않는다.

첫 검증은 독립적인 성인 배달부와 종이별 이야기로 만든다. 원작 이미지나 작가 이름을
생성 모델의 참조 입력으로 쓰지 않는다. 캐릭터·소품·배경은 원본 설계와 출처를 기록한다.
