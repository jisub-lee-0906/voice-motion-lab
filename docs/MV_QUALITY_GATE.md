# MV 품질 검증: 15초, 주인공 하나, 종이별 하나, 세 장면

상태: 수치 장면 계약과 원화 시험용 소스를 준비했다. 원화·실제 애니메이션은 아직 제작하거나 검증하지 않았다.
현재 32초 결과는 ASR → SDK → 렌더 → 재생 경로의 동작 확인 결과이며,
이 품질 기준을 통과한 작품이 아니다.

## 이번 단계의 범위

- 대회 프로젝트 `voice-motion-lab` 안에서만 작업한다.
- 이 단계에서는 레퍼런스를 조사하고, 장면 계약·품질 검증과 독립 실행 준비를 구현한다.
- 원래 ComfyUI Studio, 기존 작업·프로세스·GPU 큐·모델·환경에는 손대지 않는다.
- GPU 설치·생성 실행과 기존 작업의 자원 양도는 별도 자원 승인과 충돌 확인 후 진행한다.
- 실제 확인한 레퍼런스 표본과 해석은 [MV_REFERENCE_ANALYSIS.md](MV_REFERENCE_ANALYSIS.md)에 기록한다.

## 현재 결과에서 바꿔야 할 것

`semantic_theme()`의 세 종류 키워드 분류와 `direct_project()`의 순환 구도만으로는
가사의 문장 의미나 사건을 연출할 수 없다. `MVArtRenderer`의 정해진 인형·배경과
시간 함수 중심 움직임은 시각적 초안이다. 새로운 그림 한 장이나 빠른 GPU를
추가해도 이 구조에서 소품을 꺼내고 놓고 변형하는 행동은 생기지 않는다.

따라서 다음 결과의 핵심은 디테일이나 컷 수가 아니라 **행동과 상태 변화**다.
전사·인코딩·SDK 통과 여부는 별도 기술 검사로 유지한다.

## 독립적인 미술 방향

특정 작가의 캐릭터·프레임·고유 디자인을 복제하지 않는다. 첫 시제품은 손으로 그린 듯한
선화와 셀 음영의 인물, 선명한 실루엣, 제한된 색, 실제로 형태가 변하는 종이별로 설계한다.
종이 인형이나 단순 벡터 스티커는 미술 목표가 아니다. 세부 기준은 [MV_ART_BIBLE.md](MV_ART_BIBLE.md).

- 성인 주인공 한 명. 검은 단발, 코랄 우비, 먹색 바지와 신발, 작은 초승달 핀.
- 주인공의 옷색·머리·얼굴 비율은 장면이 바뀌어도 유지한다.
- 배경: 먹색 밤 공간과 상아색 문 안쪽. 장식용 도형을 화면 전체에 계속 흩뿌리지 않는다.
- 상징: 접힌 종이별 하나. 주머니 → 손 → 공중 → 문의 시작점으로 같은 물체가 이어진다.
- 소프트한 실사 음영·입체 패션 인형·매 컷 다른 얼굴은 이 시제품의 방향에서 탈락이다.

이 방향은 아직 사용자가 승인한 최종 미술 스타일이 아니다. 실제 레퍼런스 관찰과
원화 검토를 통해 수정할 수 있으며, 구체적인 모델이 이를 보장한다고 약속하지 않는다.

## 15초의 사건

음악은 권리가 확인된 15초 구간을 사용한다. 아래 가사 문장은 연출을 설명하는
새로운 임시 문구다. 실제 곡 가사나 ASR 결과라고 표시하지 않는다. 실제 음원이
정해지면 해당 가사의 의미·프레이즈 경계에 맞춰 문구와 타이밍을 다시 확정한다.

| 컷 | 구간 / 24fps 프레임 | 화면과 행동 | 장면 전후 상태 | 임시 의미 단위 |
|---|---|---|---|---|
| S01 꺼내기 | 0–4초 / `[0,96)` | 주머니와 손을 함께 보여주는 3/4 전신 인물. 손이 주머니로 이동하고, 접힌 종이별을 꺼내 눈높이 아래로 내민다. 처음에는 배경·카메라가 얌전해서 행동을 읽을 수 있다. | 별은 주머니 안에서 보이지 않음 → 손에 붙은 상태로 보임 | 숨겨 둔 작은 빛 |
| S02 놓아주기 | 4–9초 / `[96,216)` | 같은 손·별의 위치를 잇는 클로즈업. 손가락이 펴지고 별이 손에서 떨어진다. 별이 작은 호를 그리며 떠오르고 접힘이 열린다. | 손에 붙은 별 → 분리된 별. 손이 열린 뒤 다시 붙지 않음 | 이제 너를 놓아 |
| S03 문이 되기 | 9–15초 / `[216,360)` | 와이드로 돌아와 별과 주인공의 위치 관계를 보여준다. 별에서 나온 종이 띠가 문 윤곽을 그린다. 주인공은 시선과 어깨를 돌려 문을 본다. 카메라가 열린 문 안으로 들어가며 끝난다. | 떠 있는 별 → 문 윗부분의 같은 별. 닫힌 평면 공간 → 통과 가능한 밝은 공간 | 나갈 수 있는 내일 |

문이 화면에 갑자기 나타나는 방식은 피한다. 별에서 문의 첫 선이 출발하는 연결
프레임이 보여야 한다. 세 장면을 자막 없이 봐도 ‘꺼냈다 → 놓았다 → 길이 생겼다’가
이해되어야 한다. 이는 사람의 검토가 필요한 품질 판단이며 자동 점수로 대체하지 않는다.

## 자산 생성·제작 매트릭스

아래 수량은 제작 전에 정하는 후보 예산이다. 아직 생성하지 않았다. 모델·해상도·
메모리·실행 시간은 실제로 선정·검증한 뒤 별도 실행 계획에 적는다.

| 자산 | 필요한 최소 결과 | Stage A 미술·동작 연구의 후보 예산 | 탈락 조건 | 자동화 단계에서 필요한 것 |
|---|---|---|---|---|
| A00 캐릭터 기준 원화 | 같은 3/4 시점 전신 1장, 의상·머리·얼굴 기준 | 최대 4후보. 전부 기록하고 사람이 선택했음을 표시 | 실사/3D 방향, 팔다리 오류, 자산으로 분리 불가, 의상 핵심 누락 | 미리 정한 평가 규칙과 선택 로그. 사람의 원화 선택 없음 |
| A01–A05 행동 포즈 | 주머니·꺼내기·내밀기·손 펴기·문 보기의 5개 핵심 포즈 | 포즈당 최대 2후보. A00을 동일 기준으로 사용 | 얼굴/의상 변화, 팔·손 접촉 오류, 소품을 잡을 수 없음 | 기준 원화 조건을 유지한 생성과 행동별 검증 |
| H01–H03 손 상태 | 쥔 손·반쯤 편 손·편 손, 소품 접촉 앵커 | 포즈 자산에서 분리하거나 필요한 경우만 보완 | 손과 별이 겹치지 않음, 접촉 전후 크기 변화, 손가락 형태 붕괴 | 접촉·분리 시점을 검증할 수 있는 마스크와 앵커 |
| P01 종이별 | 닫힘·열림 상태와 명시적 접힘/변형 경로 | 직접 설계한 원본 벡터 1세트. 출처 기록 | 컷 사이 다른 별로 교체, 분리 전후 순간이동 | 같은 ID와 모양 기준을 유지한 상태 제어 |
| P02 문 | 별에서 선이 이어지는 윤곽·열림 마스크 | 직접 설계한 원본 벡터 1세트 | 별과 인과 연결 없이 등장, 패널/마스크 구멍 오류 | 별 상태에서 문의 경계가 만들어지는 액션 실행 |
| B01–B02 공간 | 밤 공간·문 안쪽, 인물과 글자를 위한 여백 | 배경당 최대 2후보 또는 자체 벡터. 선택 이력 기록 | 불필요한 디테일·실사 질감·글자·인물 포함, 인물과 미술 불일치 | 팔레트·인물 여백·카메라 확장 영역 자동 검사 |
| T01 가사 | 의미 단위별 등장·정지·퇴장과 안전 영역 | 시스템 글꼴은 읽기 전용 참조. 실제 문구 출처 기록 | 얼굴/손/별 가림, 단어 중간 줄바꿈, 가사 오인식 미표시 | 실제 전사/정렬 출처와 수정 여부, 레이아웃 자동 검사 |

핵심 포즈 다섯 장을 단순 크로스페이드하는 결과도 통과가 아니다. 팔·손의 이동 경로,
열리는 손, 별의 부착·분리, 접힘 변화가 시간에 따라 읽혀야 한다. 리깅·대체 드로잉·
제약된 짧은 생성 동작 등 실제로 검증된 표현을 선택하고 그 방법을 기록한다.

기존 LCM CPU 원화 실험 두 결과는 현재 방향에 맞지 않아 채택하지 않았다.
그 결과를 기본 MV의 원화나 이번 시제품의 성공 예시로 사용하지 않는다.

## Stage A: 미술·동작 연구의 품질 통과 조건

다음 항목 중 하나라도 실패하면 전곡이나 해상도 확대 단계로 넘어가지 않는다.

| 항목 | 통과 조건 | 확인 방식 |
|---|---|---|
| 첫 화면의 미술 | 원화·색·구도가 실제 크기에서 볼 만하며 정해진 평면 미술에 맞음 | 정지 프레임을 사용자에게 제시해 미술 방향 확인. 특정 작가와 동급이라고 주장하지 않음 |
| 캐릭터 일관성 | 세 컷에서 얼굴 구조·머리·의상·신체 비율이 같은 인물로 보임 | 원화와 컷별 핵심 프레임을 나란히 확인. 의도하지 않은 변화는 탈락 |
| 실제 행동 | ‘꺼내기·놓기·문 생성’이 자막 없이 이해되고, 손과 물체가 접촉 후 분리됨 | 동작 구간을 실제 재생해 평가. 흔들기·카메라 확대·포즈 교체만 있으면 탈락 |
| 연속성 | 같은 별이 계속 이어지고, 컷 경계에서 손·별이 순간이동하거나 복제되지 않음 | 컷 전후 12프레임씩 확인. 계약의 앵커·부착 상태도 검사 |
| 애니메이션 | 팔·손·옷·별에 의도한 준비·이동·멈춤이 있고, 형태가 녹거나 팔다리가 추가되지 않음 | 정상 속도와 느린 재생. 복잡한 자유 생성보다 검증된 작은 동작을 우선 |
| 음악과 타이밍 | 미리 정한 주요 음악 cue 3개에 행동/컷이 맞고, 문장 중간에 의미 없이 끊기지 않음 | cue와 실제 프레임을 기록. 주요 hit의 목표 오차 ±2프레임(약83ms)은 측정 목표이며 현재 성능 주장이 아님 |
| 가사와 글자 | 실제 가사가 정확하며, 얼굴·손·별을 가리지 않고 읽을 시간이 확보됨 | 원문/전사 대조와 안전 영역 검사. 정렬이 추정이면 명시 |
| 출력 | 실제 원음·영상 동기, 정상 재생·탐색, 깨진/검은 프레임 없음 | MP4·WebM 재생과 타임스탬프·오디오 길이 검사 |

측정 검사는 사람의 미술 판단을 대신하지 않는다. 기술 검사만 통과한 결과를
‘품질 통과’로 표시하지 않는다. 사용자 검토가 남으면 상태는 `awaiting_art_review`다.

## Stage A와 Stage B를 섞지 않는 기록

Stage A는 사람이 콘티·미술·후보를 고를 수 있는 연구다. 성공하더라도 ‘15초 장면 제작
가능성 확인’으로 표시하며, 노래 하나로 완성한 자동 제품이라고 소개하지 않는다.

모든 실행은 입력 권리·음원 해시·가사 출처·모델/라이선스/커밋·프롬프트·seed·
후보 수·모든 후보 경로·선택 방법·사람의 수정 종류·실행 자원을 남긴다. 실패 후보를
삭제해 성공률이 높아 보이게 만들지 않는다. 개인정보와 원음은 공개 기록에서 제외한다.

Stage B는 별도 자동화 평가다. 아래를 제작 전에 고정한다.

1. 권리가 확인된 서로 다른 노래 구간 최소 3개, 그중 한국어 가창 포함.
2. 노래 파일 외 필수 입력 없음. 선택적 가사 수정·사람의 자산 선택이 있으면 별도 항목으로 기록.
3. 모델·후보 예산·seed 정책·평가 규칙·실패/재시도 한도 고정. 무제한 재생성 금지.
4. 모든 평가 입력의 결과와 실패를 보고. 가장 좋은 한 곡만 공개해 자동화 성공으로 일반화하지 않음.
5. 사용자의 편집기 보정 없이 같은 품질 기준을 통과하는지 확인.
6. 공식 Comfy SDK 그래프가 실제 작업을 수행하고, 자산·장면 계약·출력이 같은 실행 ID로 추적됨.

Stage B에서 품질이 유지되지 않으면 ‘연구용 제한 자동화’로 남긴다. 다른 곡에서도
반복 검증하기 전까지 대회 수상 가능성이나 레퍼런스 수준을 약속하지 않는다.
