실제 사람의 녹음 대신, 이번 테스트를 위해 직접 합성한 허밍·플롭 사운드를 사용했습니다. 캐릭터와 로고도 이번 프로젝트의 오리지널 SVG입니다. 외부 음원·캐릭터·생성형 영상 서비스 없이 제작했습니다.

앱은 타이밍·음높이·어택을 분석해 선택한 경로의 진행과 표정을 만듭니다. 같은 모션 계산으로 미리보기, 애니메이션 SVG와 원음 포함 WebM을 내보냅니다. 편집용 JSON을 Studio에서 다시 열면 벡터와 소리, 모션 설정을 이어서 수정할 수 있습니다.

이 페이지는 합성 입력을 사용한 프로덕션 테스트 갤러리입니다. 실제 마이크 녹음의 사용성과 다양한 사람 목소리에 대한 검증은 별도 단계입니다.
